      --- Flow ---
'^' - Change IP moving direction to 'up'
'v' - Change IP moving direction to 'down'
'>' - Change IP moving direction to 'right'
'<' - Change IP moving direction to 'left'
'@' - End
IP also can 'wrap around'
('IP' - Instruction point)

      --- Push ---
'0' - Push to stack 0
'1' - Push to stack 1
'2' - Push to stack 2
'3' - Push to stack 3
'4' - Push to stack 4
'5' - Push to stack 5
'6' - Push to stack 6
'7' - Push to stack 7
'8' - Push to stack 8
'9' - Push to stack 9

      --- Stack ---
'+' - Push to stack a + b
'-' - Push to stack a - b
'*' - Push to stack a * b
'/' - Push to stack a / b
'\' - Push to stack b, a
'$' - Delete top element of stack
'%' - Push to stack a(mod b)

      --- I/O ---
'&' - Input number
'~' - Input char (pushes to stack decimal ASCII code of char)
'.' - Print number
',' - Print char (prints the character whose decimal ASCII code is the top element of the stack)

      --- Changing program ---
'p' - Put
